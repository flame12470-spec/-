# ระบบแชทความปลอดภัยสูง (PWA Chat Application)

ไฟล์ในชุดนี้ประกอบด้วย:
1. `index.html` - หน้าเว็บแอปพลิเคชันหลัก รองรับการเล่นเพลง ส่งสติกเกอร์ แสดงความรู้สึก (Reactions) และติดตั้ง PWA
2. `manifest.json` - คอนฟิกสำหรับติดตั้งเป็นแอปพลิเคชันบนมือถือ, iPad, แท็บเล็ต และคอมพิวเตอร์
3. `sw.js` - Service Worker สำหรับระบบแคชออฟไลน์และการแจ้งเตือนจริง (Web Push Notification)
4. `schema.sql` - โค้ดสร้างฐานข้อมูลสำหรับโปรเจกต์ Supabase
5. `icon-192.png` & `icon-512.png` - ไอคอนของแอปพลิเคชัน

### วิธีการนำไปใช้งาน:
1. นำไฟล์ทั้งหมดไปวางไว้ในโฟลเดอร์เดียวกันบนโฮสติ้งเว็บ (เช่น Vercel, Netlify, หรือ GitHub Pages)
2. เปิดผ่านเบราว์เซอร์แล้วกด "ติดตั้งเป็นแอป" หรือ "เพิ่มไปยังหน้าจอโฮม"
3. ในเมนูตั้งค่าสามารถกด "เปิดการแจ้งเตือนจริง" ได้ทันที
